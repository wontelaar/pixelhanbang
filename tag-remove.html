옷 택 지우는 방법

  1. 택이 보이는 상품사진 한 장을 선택하세요.
  2. 미리보기에서 택 위를 손가락이나 마우스로 칠하세요. 칠한 곳은 빨갛게 보입니다. 택이 작으면 ＋ 버튼이나 배율 막대로 확대하고, ‘이동’을 켠 채 끌어서 택이 보이는 곳으로 옮기세요. PC에서는 Ctrl을 누른 채 마우스 휠을 돌려도 확대·축소됩니다.
  3. ‘택 지우기’를 누르면 칠한 부분이 주변 원단으로 채워집니다. 남은 곳이 있으면 다시 칠하고 한 번 더 누르세요.
  4. 마음에 들면 ‘결과 사진 저장’을 누르세요.

이럴 때 쓰면 좋아요

  • 옷걸이에 걸어 찍은 상품사진에서 목 안쪽 택이나 사이즈 라벨이 보일 때
  • 제조사 택이 드러나 상세페이지가 깔끔해 보이지 않을 때
  • 원단 위 작은 실밥, 보풀, 먼지를 지우고 싶을 때

어떤 사진이 잘 되나요?

목 안쪽처럼 단색이거나 결이 고른 원단 위의 작은 택은 거의 티 나지 않게 지워집니다. 골지나 봉제선이 택 뒤로 지나가도 주변 선을 이어서 채워 줍니다. 택이 클수록 AI가 새로 그려야 하는 면적이 넓어지므로, 큰 택은 한 번에 칠하기보다 절반씩 나눠 두세 번에 지우면 결과가 더 자연스럽습니다.

체크나 글자 프린트처럼 뚜렷한 무늬 위에 있는 택, 접혀서 목선 자체를 가린 큰 택은 원래 무늬를 정확히 되살리기 어렵습니다. 저장하기 전에 확대해서 원단 결이 어색하지 않은지 확인하세요.

주의할 점

  • 지운 자리는 AI가 그럴듯하게 채운 것이라 실제 원단과 아주 미세하게 다를 수 있습니다. 상품의 색이나 디자인을 바꾸는 용도로 쓰면 실물과 달라 문의가 생길 수 있으니, 택이나 먼지처럼 상품과 관계없는 부분만 지우세요.
  • 처음 한 번은 AI 파일을 내려받아 시간이 걸리고, 메모리가 적은 휴대폰에서는 처리가 멈출 수 있습니다. 그럴 땐 PC에서 시도하세요.
  • 결과는 원래 사진 크기 그대로 새 파일로 저장되며, 촬영 위치 같은 사진 정보(EXIF)는 담기지 않습니다.

자주 묻는 질문

어떤 AI를 사용하나요?

모바일 기기용으로 공개된 이미지 복원 모델 MI-GAN(MIT 라이선스)을 브라우저 안에서 실행합니다. 사진은 서버로 보내지 않습니다.

잘못 지웠어요

‘지운 것 되돌리기’를 누르면 마지막으로 지우기 전 상태로 돌아갑니다. 여러 번 누르면 한 단계씩 더 되돌아갑니다.

여러 장을 한 번에 지울 수 있나요?

택 위치가 사진마다 달라 한 장씩 직접 칠하는 방식입니다. 같은 자리에서 찍은 사진이라도 옷걸이 위치가 조금씩 달라지기 때문입니다.

원본 사진이 바뀌나요?

아니요. 원본은 그대로 두고 택을 지운 사진을 새 파일로 저장합니다.
