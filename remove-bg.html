배경을 투명하게 만드는 방법

  1. 단색 배경으로 촬영한 사진을 최대 20장까지 선택하세요.
  2. 자동 인식 결과를 확인하고 필요하면 사진을 눌러 배경색과 제거 강도를 조절하세요.
  3. ‘배경 투명하게 저장’을 누르면 투명 PNG가 저장됩니다.

어떤 사진에 잘 맞나요?

흰 벽이나 촬영지, 검정 천, 파란 스크린처럼 색이 고르게 이어진 배경에 잘 맞습니다. 사진 가장자리와 연결된 배경부터 지우므로 상품 안쪽에 같은 색이 있어도 지워질 가능성을 줄였습니다.

사용 전 알아두세요

풍경이나 방 안처럼 여러 색과 무늬가 섞인 배경은 깔끔하게 제거하기 어렵습니다. 상품이 사진 가장자리에 닿아 있거나 배경색과 매우 비슷하면 일부가 함께 지워질 수 있으니 미리보기에서 제거 강도를 조절해 주세요.

자주 묻는 질문

흰색 배경만 지울 수 있나요?

아니요. 자동으로 사진의 배경색을 찾거나 미리보기에서 원하는 색을 직접 선택할 수 있어 검정, 회색, 파랑 등 다양한 단색 배경을 지울 수 있습니다.

여러 장을 한꺼번에 처리할 수 있나요?

최대 20장까지 가능하며 자동 인식을 선택하면 사진마다 배경색을 따로 찾아 처리합니다. 여러 장의 결과는 하나의 ZIP 파일로 저장됩니다.

결과 파일은 어떤 형식인가요?

투명 영역을 지원하는 PNG 형식으로 저장됩니다. 원본 사진은 변경되지 않습니다.

사진이 서버에 저장되나요?

아니요. 사진은 사용 중인 브라우저 안에서만 처리하며 사이트 서버로 전송하거나 보관하지 않습니다.
