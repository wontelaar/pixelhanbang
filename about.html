사이트 소개

복잡한 사진·영상 작업을 간단하게

픽셀한방은 프로그램 설치나 회원가입 없이 사진을 정리하고 동영상 장면을 썸네일로 저장할 수 있는 무료 웹도구입니다.

왜 만들었나요?

운영자는 10년 이상 온라인 의류 쇼핑몰을 운영하며 상품사진을 직접 준비해 왔습니다. 사진의 크기나 비율, 배경, 파일 형식 때문에 같은 작업을 여러 번 되풀이하는 불편을 줄이려고 픽셀한방을 만들었습니다. 전문 편집 프로그램이 없어도 자주 쓰는 작업을 한 화면에서 빠르게 끝내는 것이 목표입니다.

기기 안에서 처리합니다

선택한 사진과 동영상은 웹브라우저의 처리 기능을 이용해 사용자의 기기 안에서 처리합니다. 파일을 사이트 서버로 전송하거나 보관하지 않습니다.

현재 제공하는 기능

  • 사진 가로·세로 크기 변경
  • JPG, PNG, WebP 사진 용량 줄이기
  • JPG, PNG, WebP 형식 변환
  • 흰색·검정·파랑 등 단색 배경을 투명하게 제거
  • AI로 사진 속 대상을 분리해 선명한 색면 캐릭터·로고 PNG로 변환
  • 사진 위치와 확대를 조절하는 원형 프로필 만들기
  • 동영상 장면을 고르는 쇼츠·릴스 세로형 썸네일 만들기
  • 아이폰 HEIC·HEIF 사진을 JPG로 일괄 변환
  • 사진을 자르지 않는 정사각형 여백
  • 인스타그램 피드용 3분할·9분할
  • 여러 결과를 하나의 ZIP 파일로 저장

이용 환경

최신 버전의 Chrome, Edge, Safari 등 일반적인 웹브라우저에서 이용할 수 있습니다. 기기의 메모리가 부족하거나 매우 큰 파일을 처리하면 작업이 중단될 수 있습니다.

운영 원칙

  • 회원가입 없이 필요한 기능을 바로 이용할 수 있게 합니다.
  • 가능한 작업은 서버 전송 없이 사용자의 기기 안에서 처리합니다.
  • 원본 파일은 변경하지 않고 새로운 결과 파일만 내려받게 합니다.
  • 지원 형식과 제한사항을 각 도구 화면에 알기 쉽게 안내합니다.

콘텐츠와 기능은 이렇게 점검합니다

  • 각 도구는 실제 사진으로 저장 결과와 모바일 조작을 확인합니다.
  • 잘 어울리는 사진과 실패하기 쉬운 조건을 사용법에 함께 적습니다.
  • 브라우저 제한이나 처리할 수 없는 형식은 숨기지 않고 안내합니다.
  • 문의로 확인된 오류와 불편은 재현한 뒤 수정하고 안내를 보완합니다.
